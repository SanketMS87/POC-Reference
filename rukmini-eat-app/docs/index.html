Authentication

  1. Call POST /api/auth/login (demo customer demo@rukmini.com / Demo@123, demo admin admin@rukmini.com / Admin@123; local profile only).
  2. Copy the token from the response.
  3. Send it on protected calls as a bearer token:
Authorization: Bearer <token>

In the live Swagger UI, click Authorize and paste only the token. Tokens expire after about an hour. Registration always creates a customer account.

Errors

StatusMeaning
400Invalid input or business rule (unknown menu item, quantity over 20, items from several restaurants). Body: {"message": "..."}
401Missing, invalid or expired token, or wrong login credentials
403Customer token used on an ADMIN operation
404Unknown restaurant
409Email already registered
429Too many login/registration attempts from one address; wait for the Retry-After seconds

Security-layer 401/403 responses can have an empty body.
